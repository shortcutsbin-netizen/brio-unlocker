# V55 findings and implementation — 2026-10-12

V54 is rejected by the user for unreliable firing/ADS detection and excessive recording requirements. No V54 rerun/log is requested. This pass uses the supplied native source and direct feedback. Historical files remain unchanged.

The supplied engine maps `ÃAæ` to `shot`, and the native player-update callback uses that marker for weapon firing effects. V54 did not use this marker for checklist progress: it depended on local-owned bullet creation and rejected the entire observation when aim/ADS quality was insufficient. Decoder observation also occurred before the native client applied a packet batch; falling back to renderer selection/ammo on each partial delta could revert earlier updates. These are concrete source defects; they are not a claim to have reproduced every live symptom.

V55 counts native shot markers, with same-gun loaded-ammo decrease fallback, independently of angle measurement. Correlate native markers, ammo changes and local-owned pellets in either order; coalesced decreases and multiple markers conserve round count. Duplicate packet objects/IDs do not inflate counts. Copy authoritative primitive gun/slot/ammo state across partial updates. Slot replacement invalidates prior gun ammo. Native `z` removes entities and cannot be a firing update. A known gun/build state is required; clicks, remote/unknown-owner bullets, ammo -1 and excluded items are not counted.

Held right-click determines ADS/No ADS as requested. The native renderer's temporary firing/recoil steadying state cannot reclassify a hip-fire shot. Original native acknowledgement remains a separate angle-quality check; disagreement/stale/turning/ambiguous aim rejects an angle, not the already confirmed shot. Blur invalidates mode; a bounded150ms left-release tail handles delayed final firing evidence. Input observation never sends or modifies native input.

Each mode's recording target is `max(10, clip size×3)`. The old eight-sequence and stable50+50 requirements are removed from completion. Qualified angle-group count is shown separately. A recorded mode is not a theoretical maximum, exact angle table or claim of sufficient statistical coverage. Small compact muzzle-based envelopes retain their prior transform/assistance rules and only use qualified angles (minimum12 or the smaller recording target). There is no fabricated zero-angle sample when bullets/aim are absent.

**Capacity limitation:** the supplied native client has no maximum-capacity table. V55 learns the largest current loaded-ammo count observed for each gun and displays the resulting clip/target. This is a lower bound after a partly used pickup or partial reload; a fuller reload raises the target and can reopen completion. Unknown clip stays pending.1/3 rounds→10,6→18,30→90. Current loaded ammo must not be described as a source-proven maximum. A future authoritative capacity table can replace this observation without changing the requested formula.
