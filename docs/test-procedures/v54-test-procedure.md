# V54 test procedure — play normally until the checklist fills

1. On the Build Royale home screen, paste the complete `dist/brio-v54.min.js` payload once. Use ordinary settings. If **Show bullet spread** is off, enable it in Extras before playing to inspect the revised V; it is optional for measurement. Hell suppresses the test badge/cone as assistance, so ordinary non-Hell play is easiest for this run.
2. Play as many normal games as needed, using different guns naturally and firing both without right-click and while holding right-click for ADS. Use each weapon's ordinary held fire, individual clicks or single-round reload. **There is no in-game start/arm/PERF button, firing script, shot count, rarity sweep or fixed-aim exercise.** Recording and saving happen automatically.
3. **SPREAD RECON** optionally shows progress at any time; opening it does not start measurement. When the checklist is complete, or when a problem/noticeable delay occurs, use **COPY RESULTS** and upload the complete export as `logs/runs/v54-log.txt`. Report only visible problems or persistent lag. No export is required after every match.

The above-player badge turns green **Recording shots** for accepted observations and amber **Not counted** with a reason when a shot cannot be measured reliably. Its top line names the held gun/mode and progress; **Gun checked** means ADS and No ADS both qualify. Turning quickly, changing guns or entering/exiting ADS can briefly produce rejected samples; that is expected quality filtering. Idle Ready means the recorder is waiting for shots. You do not need to observe or report individual colors/counters.

A mode needs 100 accepted shot groups, at least eight firing sequences and stable observed width. Pellets do not each count as an independent shot. Reloads/new presses/normal pauses provide sequences automatically. If the count reaches100 but the box is still open, continue ordinary use: the checklist explains whether more sequences or stability are needed. Rarities share one gun entry. New evidence can reopen an unstable estimate.

Progress survives matches, refresh and reinjection in the same browser/profile. Do not clear this site's storage between sessions. If storage is unavailable, the checklist/badge warns; keep the page open and export to preserve the in-memory evidence. Source-backed never-encountered guns stay unobserved; their server availability is not promised. Grappler reads N/A. The displayed V uses observed data and stays hidden until12 accepted groups; it is not an exact server maximum.

Performance evidence is automatic during ordinary play. This pass does not request the old24-second comparison, any temporary modifier pause, a forced Hell match, map opening, win, depletion, special route or HTML hunt. Existing test-profile/restore controls remain available but are not required. Future latency isolation can use the retained diagnostic API if live evidence justifies it.
