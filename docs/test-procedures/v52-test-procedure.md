# V52 test procedure — two ordinary matches, exception-only reporting

V51 Match B was skipped. V50 was never live-tested. No omitted condition is marked passed: the entire previous surface is retained below in automated fixtures, passive diagnostics, or explicitly pending live evidence.

1. Paste the complete `dist/brio-v52.min.js` Console payload on the home screen. Open **Extras**, click **Set up normal test**, then play one ordinary match. This enables the test modifiers and all detected Gold/Red gun pairs in one click; your prior settings have a separate persistent backup. Cosmetics and warning thresholds stay as saved. The setup opens the grouped Modifiers page so the new loot grid is visible.
2. For the next match, enable **Hell** in Challenges, then use ordinary Play. During that match press your usual full-map key once: nothing should appear. Briefly turn Hell off; the map and saved assistance should return. Close the map, then turn Hell back on and finish normally. Use the terminal's **EXTRAS** button to reach the same menu during play. This is the only requested live option cycle.
3. After both matches, **COPY RESULTS** once and upload the entire export as `logs/runs/v52-log.txt`. Report **only visible problems**, such as remaining Hell leaks, a cone pointed away from fire, wrong projected storm direction, or unreadable controls/stats. Name the gun if its cone looks wrong. If nothing stands out, “no visible issues” is enough. Use **Restore saved settings** after export when you want your prior profile back.

No forced wins, special harvesting sequence, deliberate health/ammo depletion, individual challenge sweep, rarity hunting, named inventory comparison, repeated reset checks, or HTML-file hunt. Normal pickup/use/building/slot switching supply events naturally. Unencountered events stay unknown rather than becoming reporting chores.

## What the script records automatically

Every15 seconds: installed categories, concurrently active adapters, retired adapters, suppressed native draw attempts, selected tiers, reached/unobserved challenge branches, current projected target, outline cache usage and native HUD acquisition. Terminal events add a final automatic audit and both client-aim/server-aim shot comparisons. Suppression counts prove a reached native branch was gated; they cannot prove that another unrecognized visual branch was invisible.

Shot comparisons are passive and bounded, independent of the capped deep log lanes. Native bullet and local packet rotations use rotation/100 radians. Displayed half-angle degrees remain provisional: client aim, packet ordering and turning contaminate samples. No automatic shot, trajectory prediction, server mutation, or misleading fit to a finite random sample.

The projected zone should remain fixed during storm movement, changing only when the next waiting target arrives. Unknown transform/target suppresses the arrow. Silhouette borders should follow readable artwork; unsupported/unreadable assets retain the existing bounding box and record fallback. End-game stats use light-text cards and keep native header/Play/spectate controls.
