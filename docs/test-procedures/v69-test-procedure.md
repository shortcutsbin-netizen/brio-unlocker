# V69 production integration test — maximum two played matches

This is the integrated production candidate, not the design gallery. No terminal, test-profile buttons, source capture or log export is expected. Existing accepted gameplay features need exception reports only. Do not replay matches for missed events, missing loot, a win or additional artwork.

1. **Load V69 on a fresh game page.** Open https://buildroyale.io, reload to clear any older installation, and wait for the home page. Open the V69 standalone script at https://raw.githubusercontent.com/shortcutsbin-netizen/brio-unlocker/main/dist/brio-v69.min.js, copy its entire contents, and run it once using the same browser console/snippet method used for earlier suites. The readable equivalent is `src/brio.js`; do not run both files. Close DevTools before checking layout. Open the existing native (un)Locker button and the existing Extras button separately. Both headers must say **v69**. There must be no floating terminal or COPY RESULTS control. If the version differs or installation fails, stop before playing and report the issue; do not repeat an older suite.

2. **Check the home replacements and menus without playing.** Confirm the BRIO UNLOCKED logo, bottom socials strip, GitHub link and display-only Discord handle **ads0210**. The Discord badge should not navigate. The separate side-ad panel should say This session and show no completed matches. Native Play, name, account and other home controls should remain usable; no extra Play button or duplicate Locker/Extras buttons should appear. Check that menus fit your normal window, scroll to all controls, and close with Close/Done or Escape. Locker and Extras must remain separate menus with no direct cross-menu navigation. In Extras, check the Hell and General Advantages title/action rows and the full-width descriptions underneath them.

3. **Check the integrated Locker before match 1.** Visit Skins/Body, Skins/Head, Pickaxes, Wraps, Trails, Gliders and Emotes. Native choices should populate; Head/Body/Pickaxe/Glider should also contain the 16 BRIO original sets. Search and All/Originals/Uploads filters should work where applicable. Select a matching original head, body, pickaxe and glider from one set. Check centered card art and the running preview; selecting a pickaxe should show it held, selecting a wrap should show a wrapped SCAR preview, and selecting a glider should show the side-facing glider with no held item. A selected trail should begin under the player and extend behind them. Check the four emote slots and their selections. You may use one small existing custom upload if desired; no new upload is required. Choose the cosmetics you want to take into match 1. Do not try all 16 sets in separate matches.

4. **Prepare normal modifiers.** In Extras → Challenges, turn Hell off and turn off any individual challenges left from earlier testing. Visual-only Flashlight/Monochrome can remain off for this integration pass. In Modifiers, first enable one excluded option such as Nearest chest, then press **General Advantages**. It must enable the described advantages, deselect excluded modifiers such as Nearest chest, set other-player inventory size to Large, restore default warning thresholds, and leave Hell off. Warning defaults are Health 20; Light/Medium/Heavy/Shells/Rockets/Grappler ammo 30/30/10/15/5/5; Wood/Brick/Metal/Scraps 30/30/30/1. Turn one included option off and back on to confirm the preset stays editable. Enable Custom crosshair separately, choose one of the 36 inline shapes, a clearly colored swatch and a comfortable size. Optional imports remain available. Check an indicator color or warning threshold only if desired; restore the desired setting afterward.

5. **Play match 1 normally.** Check the selected cosmetic art in motion, held pickaxe and its inventory icon, glider when naturally visible, crosshair shape/color/size, approved indicator silhouette/upright distance/name, and an exception-only glance at existing advantages. All gliders invisible is enabled by General Advantages, so briefly turn it off in **Extras**, the small in-match settings button at bottom right, if you want to see your selected glider. Turn it back on if desired. When naturally visible, the bold projected next-zone edge should match the next-zone square on the minimap, with the appropriate sides appearing as they enter view. No special storm/loot/event hunt is needed.

6. **Check the remaining No map fix in that same match.** Open Extras → Challenges and enable No map. The minimap, map counters and numeric/icon storm countdown must disappear. Press your normal full-map key: the large map must not be visible. Turn No map off and confirm normal minimap/countdown/full-map rendering returns; close the map normally. Separate storm/event/status messages, elimination announcements and kill feed should remain visible whenever naturally produced. Briefly enable No inventory/item bar if convenient: your inventory/materials/ammo and own HUD name should hide, then restore when switched off. Do not add a match for an unobserved message or storm side.

7. **Review match 1’s actual end panel.** Let the match finish naturally if practical. The new Match report must occupy the native stats/pass panel, while native result heading, Play again, spectate and Battle Pass navigation remain available. Check the centered elimination/damage/build/time values against native totals where shown; look over weapon holding time, observed loss, travel, projectile/player counts, eliminated names and derived rates. Scroll as needed. Missing values should be shown as unavailable/dashes rather than fabricated. If Battle Pass browsing is available, open it and return: native browsing should work and the report should return. Back on home, This session should show one completed match and the corresponding win/placement/totals. If there was no terminal result, report that; do not invent an outcome or add a replacement match.

8. **Play match 2 with Hell, if match 1 did not expose a blocking failure.** Before Play, enable Hell in Extras → Challenges. Modifier controls should show off/locked; individual gameplay challenges should show their enforced settings/highest tiers. Flashlight and Monochrome are independent visual modes, so leave them off for this check. Start one match. Confirm both maps/countdown, inventory/own HUD name, health/shield HUD, crosshair, other players, builds, loot/crates and projectiles are hidden where naturally encountered. Separate status messages/elimination announcements and kill feed must remain visible. Use the in-match Extras button to turn Hell off briefly: your saved choices and normal game presentation should restore. You may turn it back on or finish normally. No forced win or additional match is needed.

9. **Review session accumulation and reinjection without playing again.** After match 2’s terminal result, the session panel should show two completed matches, summed kills/damage/builds/time, wins and win rate based on known placements, average placement and other available aggregates. Scroll through its full content. If either match had no terminal result, only completed results should count. Open/close menus a few times and check for duplicate panels or obviously worsening responsiveness. Run the same V69 script once more on the home page: there should still be exactly one set of menus/home panels, session totals should reset to zero, and saved cosmetic/Extras choices/uploads should survive. There should be no residual terminal or old overlay. Do not play another match.

10. **Report observations in chat.** State your browser/window size, that both menu headers said v69, whether home/menu replacements looked right, cosmetic/preview exceptions, crosshair color, No map hiding/restoration, Hell/protected text behavior, match-report/native navigation, session totals and reinjection behavior. Mention any small error message shown in a menu footer verbatim. Screenshots are useful for a specific visual defect but are optional. Mark unencountered conditions as unobserved. **No log file, COPY RESULTS, recon script or additional asset retrieval is required.** Stop at two played matches even if some checks were missed.
