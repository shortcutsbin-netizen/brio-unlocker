# V55 short procedure — firing and mode counts first

1. On Build Royale home, paste the complete `dist/brio-v55.min.js` once. Use ordinary settings and ordinary Play. Recording needs no arm/start button.
2. With a naturally obtained gun, fire normally without right-click, then with right-click held. Check that the badge and the corresponding **No ADS / ADS** column advance. Reload normally with spare reserve ammo; the learned clip size and target appear beside the counts. Use clicks/automatic fire/single-round reloads naturally. No fixed aim, manually counted clips or100-shot requirement.
3. Optionally open **SPREAD RECON**: target per mode is **max(10, clip size×3)**. A one-/three-round gun targets10, a six-round gun18, a30-round gun90. All requested utility/vaulted entries are absent; **Heavy Sniper remains**. Normal later games/reinjection retain V55 progress.

Report only missed/inflated firing counts, wrong ADS column, wrong clip/target, visible failures or noticeable delay. Stop and report a failure without completing the whole gun catalog. No required success-run upload; **COPY RESULTS** is optional for diagnosing a V55 failure. No V54 log/rerun, rarity hunt, forced Hell/map/PERF test or all-gun grind.

Confirmed firing counts even when angle data is missing/rejected. The checklist separately shows **angle samples**. **Recorded** means the requested firing target was reached, not that the spread envelope is a proven maximum. The optional Show bullet spread still needs qualified angular evidence, so an absent cone does not mean a confirmed shot was missed.

Clip size is learned from the largest native loaded count observed. A partly used pickup/partial reload is a lower bound; a fuller reload updates the target and can reopen recording completion. Unknown clip stays pending. The supplied client has no maximum-magazine table, so that limitation is explicit rather than a guessed fixed number.

ADS means held right-click. A brief release tail associates delayed last-shot evidence with the prior held mode; blur invalidates mode until a fresh input event. Hell hides assistance while recording continues. Unencountered native visuals remain pending.
