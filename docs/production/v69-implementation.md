## Maintenance

Current source is generated reproducibly from immutable V68 operational core plus explicit production transforms and modules: `npm run build:production-source`, then `npm run build`. Build refuses to overwrite a differing published version archive. Edit production templates/styles/bindings/resources or the explicit integration transform, regenerate and run meaningful checks; do not hand-edit only generated source. Existing historical tests/probes/design galleries stay in the repository for provenance but are not shipped. The default test command is the production suite; `test:legacy` targets archived V68 runtime explicitly. Browser fixture uses `/tmp/chromium` or BRIO_DESIGN_CHROME; missing browser dependency is an executor setup concern, not a player installation requirement.
